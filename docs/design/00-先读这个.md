## 一分钟：这是什么

**家园模拟（RimWorld）＋ 小队冒险刷宝（暗黑/Chronicon）＋ 程序化幻想建造（Tiny Glade）
＋ 八方旅人式像素立体美术。**

白天经营一个自己会转的村庄；晚上带村里的某个居民下魔域刷装备；
带回来的东西让村庄更强。

> ### 一句话辨别
> **基地里的居民，就是你冒险世界的一部分。**
> 培养铁匠 → 他做传奇武器 → 你带着它进魔域 → 带回材料 → 升级村庄。
>
> **任何取舍，优先保住这个闭环。** 保不住它，这就是"又一个刷装备游戏"。

---

## 现在在哪

**V0.1 —— 目标是把一条完整循环跑通，不是把功能做全。**

```
家园 lane：  地形农业 → 昼夜天气 → 光影 →【建筑暂缓】
装备 lane：  基础物品 → 词条 → 品质 → 镶嵌        ← 可立即开（零耦合）
副本 lane：  蓝图（存墙）→ 房间图 → 内容生成
战斗 lane：  怪物数据 → 伤害 → AI → 动画          ← 最大的一块
```

---

## ✅ 现在有四条并行的 lane（Willow 2026-09-12 定）

**并行 ≠ 什么都同时做。四条 lane 各自拥有不相交的文件，互不碰。**

| Lane | 拥有 | 依赖 | 状态 |
|---|---|---|---|
| **家园** | `world/terrain/` `world/npc/` `character/` | — | 进行中 |
| **装备** | `data/equipment.gd` · `world/equipment/`（新） | **零** | **最适合现在开** |
| **副本** | `world/dungeon/`（新） | 房间系统（已有断言） | 可开 |
| **怪物 / 战斗** | `actors/` · `combat/`（新） | 相机第二配置 | 最大的一块 |

**家园 lane 的具体内容**：地形（草坪→土地→耕地→播种→成熟）· 昼夜天气 · 光影 · 篝火发光。
用**一栋固定的房子**把所有其它功能跑通。

**装备 lane 为什么最适合先开**：它是**纯数据 + 纯函数**（基础物品 + 词条 + 品质 + 镶嵌），
**不碰任何正在跑的东西**，直接进 `tests/unit/`，不需要世界、不需要相机、不需要新场景。

### 🔴 唯一的红线

> **家园那条 lane 不能停。**
> 它卡着生产链 —— 也就是卡着「家园能自己转」。
>
> ℹ️ **欠债 22 已经关了**（2026-09-15）—— 而且它其实一直是通的
> （那句"到不了箱子"是**读得太早**）。现在有活断言盯着
> `production chain ran live: chest wheat 8 -> 6, bread 0 -> 1`。
> **红线本身没变**：这条链子一旦断了，上面那些都白做。
>
> **三条新 lane 各自独立，但它们都靠"家园能自己转"才变成一个有意义的游戏。**
> 家园那条停了，最后就是**三个半成品 + 一个跑不起来的循环**。

## ⛔ 不做什么

**跑题几乎总是从"顺手做点别的"开始的。这一节就是防线。**

| 🚫 | 为什么 |
|---|---|
| 自由摆砖块 / Tiny Glade 式结构生成 | **建筑暂缓** —— 一栋固定房子足够验证其它一切 |
| 不同海拔的地形编辑 | **现在全是平地**（2026-09-12 明确） |
| 联机 | V0.4，而且架构约束已经写在总纲 §82 |
| **ECS** ｜ **EventBus** ｜ **把数据表改成 JSON** | **Core Architecture V1.0 已冻结为"不做"** |
| 开放世界 / 100+ NPC / 完整经济 | 总纲 §82 的非目标清单，一条没取消 |
| 重写任何正在跑的系统 | **只加边界和接口** |
| **一条 lane 顺手去改另一条 lane 的文件** | 并行的前提就是**文件不相交**；相交了就不是并行，是冲突 |

## 三条铁律

1. **动手前先跑自检。不绿就先修基线，别叠新功能。**
2. **踩到 bug 先加探针把数字量出来**，不要凭猜 ——
   这个项目为"**看起来是绿的绿数**"付过好几次代价。
3. **代码与注释全英文；游戏内文本必须 ASCII**（防豆腐块）；
   **素材可以进仓库，但必须记来源** —— 见下。

### 素材规则（2026-09-15 起，Willow 解冻）

原来的第三条是「**美术全部占位，不提交真实素材**」。它同时在干两件事：
① 美术方向没定时让仓库保持可替换；② **绝不提交法律上发不出去的东西**。
① 已经用完了（方向定了）；② 不会因为①用完就消失 ——
**所以是换掉它，不是删掉它。** 新规则：

> **素材可以进仓库，但每一条都要在 `docs/CREDITS.md` 记 来源 / 作者 / 授权，
> 且授权必须允许再分发（MIT / CC0 / CC BY）。授权不明的，一律不收。**

CC BY 还有下半句：**署名要能到玩家手里**，不能只躺在仓库里。
游戏里目前**还没有 credits 界面** —— 这句写在这里是为了让这笔账被记着，
而不是等人想起来。

## 开工三步

```bash
GODOT="D:/privacy/Openclaw/Godot-4.7.2/Godot_v4.7.2-stable_win64.exe"

# ① 冒烟：期望 133 OK / 0 FAIL / 0 ERROR
"$GODOT" --headless --path D:/cozy/cozy-game-v2 --quit-after 4500

# ② 单元：期望 12 套件 / 987 检查 / 0 失败
"$GODOT" --headless --path D:/cozy/cozy-game-v2 --script res://tests/unit/run.gd
```

> **两个开关**（都在 `main.gd` 顶部），它们说的是两件事：
>
> | 常量 | 现在 | 管什么 |
> |---|---|---|
> | `HOUSE_ENABLED` | **`true`** | 房子在不在。**它是一个预制房** —— `_build_house()` 是手工写死的 8 墙 3 板 1 梯，**从来没走 outline 生成器** |
> | `BUILDING_ENABLED` | **`false`** | **能不能在运行时画墙**。关掉的是建造工具和 live-rebuild 测试 —— **那是欠债 22 唯一的触发条件** |
>
> 启动会打一行 `runtime building: PARKED, 2 thing(s) NOT DONE`。
> **`HOUSE_ENABLED=false` 时是 89 OK**（房子连同 12 组检查一起停用，也会打 PARKED）。
