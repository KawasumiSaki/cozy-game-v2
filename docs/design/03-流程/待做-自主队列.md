## D · 草地（Willow 2026-09-15 指定参考项目）

**参考**：`github.com/DylearnDev/Dylearn-3D-Pixel-Art-Grass-Demo`（代码 **MIT**，
美术 **CC BY 4.0**，logo 不可用）。调研结论与三个坑已写进
`01-板块/ENV-环境系统-V1.0.md` / `docs/CREDITS.md`。

**它是怎么做的**（量过的）：

```
Demo/SubViewport(640×360) → Floor(MeshInstance3D) → Grass(MultiMeshInstance3D)
Display/ViewportTexture(Sprite2D)     ← 把 640×360 拉满屏
Grass   instance_count = 40000, visible_instance_count = 30000
Floor   Floor.gdshader  = 两张噪声贴图在世界 XZ 上阈值切色块 + toon + 世界空间云影
Grass   Grass.gdshader  = 顶点风(世界空间噪声) + 视角风 + 假透视 + 角色推开 + 5 fps 量化
```

**我们这边**：

```
scatter: 2011 instance(s) in 4 mesh(es), 4096 candidate(s)
scatter density: grass=0.42        ← 0.42 撮/m²（SAMPLE_STEP = 1.0 m）
植株材质：CozyPixelArt.make_billboard_material() = StandardMaterial3D
          BILLBOARD_FIXED_Y + TRANSPARENCY_ALPHA_SCISSOR + SHADING_MODE_UNSHADED
```

**⚠️ 三个坑（先看再动手）**：

1. **它的"像素感"有一大半来自 640×360 的 SubViewport** —— 那正是本项目**停掉**的
   **ENV V0.1 PixelRenderer**（阻塞区）。`ART_PROFILE.md` §2 的原话是"第一版优先让资产
   本身具备正确像素密度，**再根据实际截图决定**是否增加全屏低分辨率后处理"。
   **Willow 未就此表态 → 草地这一版不走它，做完让她开 GUI 看截图再定。**
2. **光照口径**：demo 的草是 toon + 云影；我们的植株是 `UNSHADED`，且
   `_light_the_world()` **只调 `objects`**（草/树/石头不在里面）。
   → 只照亮草会出现"夜里草暗了、树没暗"。**Willow 已说可以先用他们的方案，
   树和石头用差不多的一套** —— 所以三样一起上光照，别只改草。
3. **密度**：目标 10–30 撮/m²（现在 0.42）。`scatter rebuild cost: 149.0 ms
   = 145.5 ms sampling + 3.3 ms mesh build` —— **采样按候选点算（跟密度无关），
   mesh build 按实例数算**。密度上去要**先量**再决定。`INVARIANTS` 的
   「实例化不是可选的」是唯一活路：一片草 = 1 个 MultiMesh。

**第一刀（ENV V0.4 原话「加进现有散布 shader，不是新系统」）**：
把草这一档的 `StandardMaterial3D` 换成 `ShaderMaterial`，抄 demo 的四个技巧
（世界空间噪声风 / **绕根部**旋转 —— 注意我们的 quad 是"抬起半个身高"贴地的 /
量化帧率 / accent 变化），噪声纹理**程序化生成**。headless 能验的照例进断言。

**两个必须记住的数/事实**：

1. **⚠️ 队列里那个 demo 的数字要当心**：`instance_count = 40000` 是在
   **640×360 的 SubViewport** 里，而且它**就是这个项目的像素感来源之一** ——

2. **`detect_3d/compress_to` 默认 `1`** —— 贴图第一次进 3D 被换成 **VRAM 有损压缩**，

而且它当场抓到一个真错：**Godot 不允许 `fragment()` 里提前 `return`**
（编译错误，整个材质掉回默认 → 草一片都不动，而所有计数/指纹/摆放断言全绿）。
新增的 `vegetation material: N of M kind(s) drawing` 就是抓这个的。
**教训**：材质编译失败时，**只有"渲染"这一件事坏了，而所有断言测的都是"摆放"。**
