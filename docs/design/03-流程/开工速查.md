## 1. 三十秒：基线是不是绿的

```bash
GODOT="D:/privacy/Openclaw/Godot-4.7.2/Godot_v4.7.2-stable_win64.exe"

# ① 冒烟自检
"$GODOT" --headless --path D:/cozy/cozy-game-v2 --quit-after 4500

# ② 单元测试
"$GODOT" --headless --path D:/cozy/cozy-game-v2 --script res://tests/unit/run.gd
```

**期望：两条都是 0 FAIL、0 ERROR。** 数字以机器为准。

**数错了会把结论整个反过来**，所以计数命令本身是规定动作：

```bash
... 2>&1 | grep -c "ERROR"    # 正确：要合流，且不收窄前缀
                              #   只收 stdout 会漏 Godot 写在 stderr 的 ERROR
                              #   收窄成 "^ERROR" 会漏 SCRIPT ERROR
grep -c '\[FAIL'              # 正确
grep -c '\[FAIL\]'            # 错误！会漏掉所有 [FAIL, 原因] 形式的失败
```

## 2. 动手之前 —— 踩过的坑，按"你要碰的东西"分

### 2.1 加新东西

| 要加 | 先知道 |
|---|---|
| **任何 `class_name`** | **必须跑一次 `--import`**，否则报 `Identifier "CozyXxx" not declared` |
| **`main.gd` 里的函数** | **`main.gd` 已经有一个 `_process`。** 再加一个 = parse error，整个游戏起不来（这个坑 2026-09-15 刚踩过）。新逻辑挂进已有的那个 |
| **一个 state（`CozyXxxState`）** | **必须有 `id`。** `CozyEntityRegistry` 按 id 查 —— 没有 id 会把**整个注册表**拖垮（`entities()` 走遍每个 kind），`_world_to_dict()` 抛错 → 存档是空的 → 几十条断言跟着倒 |
| **一个新的实体 kind** | 注册表的 `per_kind` 表是**手写的**，要加进去。现在有断言看着（"注册的每个 kind 都在这张表里"） |
| **新的交互点类型**（`INTERACT_*`） | 必须进 `CozyObjectDefs.PLAYER_VERBS`（玩家用）或某工种的 `point_types`（居民用）。否则 `test_resource_chain` 会红 —— **它是对的**，不是要你绕的 |
| **一个 UI entry**（右键菜单） | `ui/context_menu.gd` 的 entry **只读 `label` / `hint` / `disabled`**。写别的键会**静默失效** |
| **一个 HUD 分类** | `ui/hud.gd` 的 `CATEGORIES` 里 `built: false` 的项是**"没有消费者"的清单**，不是装饰。做完了要改成 `true` |
| **真素材** | 进 `assets/art/` **必须记 `docs/CREDITS.md`**（来源/作者/允许再分发的授权）；`.import` 要手改 `detect_3d/compress_to=0`，否则进 3D 被换成 VRAM 有损压缩 |

### 2.2 改已有的东西

| 要改 | 先知道 |
|---|---|
| **shader** | ① `fragment()` **不能提前 `return`** —— 那是**编译错误**，整个材质掉回默认，而**所有放置类断言照样全绿**（只是整片田隐身）。② **headless 会真的编译 shader**，`SHADER ERROR` 会打出来 —— 别以为要开窗口才能验 |
| **地形 chunk 的派生旗标** | `has_water` / `has_farmland` **不在存档里**，是从格子重算的。`from_dict` 走的是直接写数组，**不重算** —— 加新旗标要记得在那里补 |
| **散布密度** | `SAMPLE_STEP` 是**候选点**间距（贵，二次方），`cluster` 是每格长几株（便宜）。**密度买在 `cluster`，不要在格点上加密** |
| **素材尺寸** | 世界尺寸 = **像素数 ÷ `CozyPixelArt.PIXELS_PER_METRE`**（60，来自 `ART_PROFILE.md` §2）。`PLACEHOLDER_SIZE` 是欠债 —— 占位图不在密度上，`_check_scatter` 会打印每个差多少倍 |
| **配方查表** | `CozyRecipeDefs.for_point()` 返回**配方那一行，不带 `id` 键**。要产物读 `row["outputs"]`，别再传 `row["id"]` 给 `outputs()` |
| **光照** | `_light_the_world()` **只调 `objects`** —— 草/树/石头不在里面。只给草上光照会出现"夜里草暗了、树没暗" |
| **玩家的东西** | **两个账本**：玩家 `player_state.pack`，村庄 `building.inventory`。两者形状、方法名、单位**完全一样**，所以写错是**看不见的** —— 有断言盯着 |
| **相机 / 操作手感 / 画风** | **停下来问 Willow。** 相机锁定 yaw 180 / pitch 40，`L` 仅调试；右键是世界的选择手势 |

### 2.3 判断"这东西做完了没有"

**"声明了没有消费者"是这个项目最贵的习惯**（`INVARIANTS` 里八条）。
加一个字段/接口/交互点时，先问：**谁会读它？** 读它的东西今天存在吗？

反过来也成立：**功能做完了，但玩家看得见吗？** 玩家背包写进去了、
HUD 上却看不到 —— 这种"循环通了但结果是隐形的"有断言查不出来，因为它读的是状态不是屏幕。

## 3. ⚠️ 文档里的数字会过期 —— 先重跑，再信

**已经发生过两次：**

- 交接里写"冒烟 139 OK"，实测 **137**（记成 bug 处理了）
- 队列里记"快路径把 40 ms 降到 0.17 ms"，**没有复现**，实测 ~8 ms

**所以：**
- 看到文档里的性能/计数数字，**当成一个假设，不是事实**。重跑一遍，把新的写回去。
- **一个写进文档、没人重跑的测量值，就是一个凭猜的数字。**

同一条的另一面：**踩到 bug 先加探针量出来，不要凭猜。**
要盯"看起来长什么样"，**截一张图**（`--cozy-shot <path>`，要真窗口；headless 画不出东西）。

## 5. 不该忘的规矩

**三条铁律**
1. **动手前先跑自检。不绿就先修基线，别叠新功能。**
2. **踩到 bug 先加探针把数字量出来**，不要凭猜。
3. **代码与注释全英文；游戏内文本必须 ASCII**（防豆腐块）。
   **素材可以进仓库，但必须记来源**（见 `docs/CREDITS.md`）。

**每个板块至少新增一条断言**（不是打印）。
**没红过的断言不算断言** —— 新断言要先把代码改坏看它红一次。

**两个开关**（`main.gd` 顶部）：`HOUSE_ENABLED`（房子在不在）·
`BUILDING_ENABLED`（能不能在运行时画墙 —— 欠债 22 的唯一触发条件，现在是 `false`）。

**不自动弹 GUI 窗。** 验证只用 `--headless`；要截图或看效果先问 Willow。
Godot 跑的是 **`gl_compatibility`**，不是 Forward+。

**收工五处**：板块笔记 → 目录 → 开发日志 → 仓库 `docs/ROADMAP.md` → git 提交。
