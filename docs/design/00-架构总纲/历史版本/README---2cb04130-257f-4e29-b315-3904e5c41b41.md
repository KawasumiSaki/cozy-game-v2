# 🎮 CozyVale · 暖境

> 治愈幻想风 **家园经营 + 副本打宝** 的 2D 独立游戏
> 立项：2026-09-04 ｜ 引擎：Godot 4.7.2 ｜ 目标平台：Steam（先用网页 demo 验证）
> 本文件用于整体审核，随开发更新。

---

## 0. 一句话

在蓝天白云的大草地上建一座自己的温馨家园（RimWorld 式），养一群小人分工干活；
同时组队出门打程序化副本、爆带随机词条的装备（Chronicon 式），越打越强、反哺家园。

**基调**：治愈、慢节奏、无失败惩罚。像龙猫／风之谷那种明亮的幻想田园。

---

## 1. 设计理念

- **明快治愈的幻想风**：大草坪、蓝天、白云、花海、雪原——视觉第一目标是"想住进去"。
- **双循环咬合**：
  - 内循环（家园）：采集 → 建造 → 接水/种地 → 养小人。
  - 外循环（冒险）：出图打副本 → 掉装备 → 词条/镶嵌变强 → 回来升级家园/养更强的小人。
- **轻量混合，不做硬核**：不是硬核模拟经营，也不是硬核动作刷子；重点是"暖 + 有收获感"。
- **数据驱动**：所有材料/物品/建造物用数据表定义，换美术皮不动逻辑（为后续材质包铺路）。

---

## 2. 玩法总览

### 2.1 家园层（RimWorld 式）
- 正上方俯视 2D 视角，Y 轴排序。
- 玩家指挥小人：走路、采集、建造、种地、做饭。
- 建造物 = **类型 × 材料**：墙／地板／火堆／箱子／床……用木头或石头造，颜色/属性随材料变。
- 小人分工：10 项技能 + 激情机制（见 §3.5）。

### 2.2 世界层（生态大地图）
- 每局**随机种子**生成一张 160×160 的大地图，地形各异。
- 8 种生物群系：海／湖／沼泽／雪地／草原／花海／森林／山。
- 时间与**四季循环**：春→夏→秋→冬，影响视觉（色调/雪/落叶/昼夜）与种植。

### 2.3 冒险层（Chronicon 式副本）
- 家图边缘的**传送门** → 程序化生成的副本（不同生态主题）。
- **实时动作战斗**（手感参考 Chronicon）。
- 掉落**未鉴定装备** → 用鉴定卷轴揭示随机词条 → 白/蓝/黄/紫品质 → 打孔镶嵌宝石。

### 2.4 成长线
技能等级（0~20）× 装备强度 × 家园规模，三条线互相供养。

## 3. 系统设计细节

### 3.1 世界生成（已实现 M2a）
- 地图 `160 × 160` tile，单格 `32px`。
- 三张噪声叠加：
  - **假纬度** `n = ty/h`：上方冷、下方暖。
  - **海拔** fBm 噪声 → 深海/海/滩/平原/丘陵/山/雪顶。
  - **湿度** fBm 噪声 → 沼泽/森林/花海/草原。
- 分类规则（`classify_biome`）：海拔 <0.28 判水域；>0.80 判雪顶或山；陆地再按"纬度+海拔修正的温度"和湿度切分。
- **海岸沙地**：水域旁一圈陆地自动染沙色。
- **出生点**：从地图中心螺旋搜索"草原/花海/森林 且 近水"的宜居格。

### 3.2 生物群系

| 群系 | 特征 | 资源 |
|---|---|---|
| 海 / 深水 | 不可走 | — |
| 湖 | 不可走（淡水） | — |
| 海岸 | 沙地 | — |
| 草原 | 宜居平地 | 稀疏橡/桦树、浆果 |
| 花海 | 装饰性强 | 花、少量桦树 |
| 森林 | 树木密集 | 橡/枫树、浆果 |
| 沼泽 | 减速 + 特产药草 | 药草、橡树 |
| 针叶林(泰加) | 冷带林地 | 松树 |
| 雪地 | 寒冷 | 少量松、水晶矿 |
| 山 / 雪顶 | 不可走、富矿 | 石灰岩/砂岩/花岗岩/大理石/板岩、铁/铜/金/水晶 |

> 具体手感（海占比、雪线高低、生态块大小）当前挂在"待调"，等你试玩反馈。

### 3.3 材料体系（数据驱动，`data.gd`）

- **木质**：橡 oak / 松 pine / 桦 birch / 枫 maple
- **石质**：石灰岩 / 砂岩 / 花岗岩 / 大理石 / 板岩
- **矿石**：铜 / 铁 / 金 / 水晶
- **植物**：浆果 / 沼泽药草 / 花

每个材料有占位色 + 名称，后续替换为贴图路径。**建造物、家具、装备都为「类型 × 材料」变体**，所以换美术不动代码。

### 3.4 采集 / 背包 / 建造（M2b，进行中）

- **采集**：点资源节点（树/岩石/矿脉/浆果/药草/花）→ 小人走过去 → 自动采集入背包。
- **背包**：按材料类别统计（木/石/矿/植物），支持具体材质分堆。
- **建造**：选建造类型 → 消耗对应类别材料放置；每件记录实际使用的材质（决定外观色）。
- **自动存档**：每约 20s 存一次（网页版 localStorage），刷新可续；提供 NEW 重开。

### 3.5 小人系统（M3 计划）
- **10 项技能**：射击 / 近战 / 种植 / 烹饪 / 研究 / 建造 / 搬运 / 挖掘 / 采集 / 医疗（0~20 级）。
- **激情机制**（RimWorld 式）：厌恶＝不可指派 / 无感 ×1 / 感兴趣 ×2 / 热爱 ×4 经验倍率。
- **需求**：饥饿、心情（基础版）。
- **任务分配** + **装备栏**（武器 / 衣服）。

### 3.6 种植 / 烹饪 / 季节（M4 计划）
- 土壤 → 播种 → 生长/浇水 → 收获 → 烹饪台 → 喂饱小人。
- 季节完整接入：春夏种、秋收、冬休；温度影响小人。

### 3.7 副本 / 战斗 / 装备词条（M5 计划）
- 家图边缘传送门 → 程序化副本（生态主题：雪洞 / 火山 / 沼泽遗迹…）。
- 实时战斗；掉落未鉴定装备。
- **词条系统**：随机属性，鉴定卷轴揭示；品质白/蓝/黄/紫；可打孔 + 镶嵌宝石。

## 4. 技术架构

### 4.1 技术栈
- **Godot 4.7.2 stable**，**headless 代码优先**（服务器无 GPU / 无图形编辑器）。
- 语言：GDScript。渲染后端：`gl_compatibility`。
- 导出：**Web（web_nothreads）**，浏览器直接跑，作为迭代验证载体。

### 4.2 文件结构
```
~/cozy-game/
├── main.gd            # 主逻辑：世界生成 / 绘制 / 输入 / UI / 存档
├── data.gd            # 数据表：材料 / 节点 / 建造物（数据驱动核心）
├── main.tscn          # 主场景（挂 main.gd）
├── project.godot      # 项目配置（分辨率 / 渲染 / 纹理过滤）
├── export_presets.cfg # Web 导出预设
└── build/web/         # 导出产物（部署到 suinsight.space/game）
```

### 4.3 核心设计
- **单场景 `Node2D` + 程序化绘制**：现在美术全是 `_draw()` 里的矢量色块，零外部资源、零素材依赖。
- **世界数据 = 一维数组网格**：`biome_grid`（群系 id）、`node_grid`（节点 id）用 `ty*W+tx` 索引，紧凑高效。
- **渲染策略**：地面烘焙成一张 `ImageTexture` 一次画；树/石/小人/方块按 Y 值排序后逐个画，实现正确遮挡。
- **相机**：`Camera2D` 跟随小人 + 边界限制 + 缩放（0.15~2.4）。
- **存档**：`JavaScriptBridge` 读写 `localStorage`，JSON 存「种子 + 位置 + 背包 + 建造物 + 已采集格」。加载时用种子重建世界再套用增量。
- **UI**：`CanvasLayer` + `Control` 预设锚点，底部操作栏 / 建造面板 / 状态标签。

### 4.4 构建 & 部署流水线
```bash
# 1) headless 跑一遍抓错（解析/运行时）
~/godot/godot --headless --path ~/cozy-game --quit-after 8

# 2) 导出 web
~/godot/godot --headless --path ~/cozy-game \
  --export-release "Web" build/web/index.html

# 3) 部署
cp -r build/web/* /var/www/suinsight/game/
```
- Demo：**https://suinsight.space/game**（HTTPS，nginx 已配 `certbot` 自动续期，`/game/` 不缓存）。
- 服务器：腾讯云 4C/3.6G/40G，**无 GPU，只能 headless 构建**。

## 6. 美术方向

- **目标风格：像素风**（16px 网格 + 最近邻过滤 + 整数倍缩放）。
- **现状**：M1/M2a 全是占位矢量色块（程序生成草地 + 圆润小人），仅为验证手感。
- **策略**：数据驱动 → 后续 Willow 定好像素路线、补齐材质包后**换皮即可**，逻辑不返工。
