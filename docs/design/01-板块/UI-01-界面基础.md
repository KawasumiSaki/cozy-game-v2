## 一句话
把「一个 Label 六行字」换成能用的界面，并且**让已经写好却够不到的系统变得可达**。

## 交付了什么
- **`CozyUiTheme`**：设计令牌（配色/间距/尺寸）作为数据，改一处换整体气质
- **`CozyHud`**：顶部状态条 + 底部工具栏 + 右侧信息面板
- **`CozyContextMenu`**：右键菜单，**按光标下实际是什么**生成条目
- **工具按操作性质分组**：`建造 | 地形 | 摆放`，组间有分隔线
- **地形工具首次可达**：Dig / Fill / Clear 接上 `CozyTerrainIntent`

## 关键决策

### 工具按**操作性质**分组，不按结果物
文档 §24 明确「门窗是 Wall 的属性」。如果把 `Door` 和 `Wall` 并列做成独立工具，
**等于把 V2-16 打回原形**。同理 `Roof` / `Foundation` **是推导出来的，不是放置的**。

所以调色板是 `建造（轮廓/墙）| 地形（挖/填/清）| 摆放（家具）`——
**门和屋顶不出现在入口，它们是结果**。

### 右键菜单按**探测结果**生成，不是固定列表
在地面上给「Remove wall」是个**会静默失败的动作**，比不提供更糟。
菜单条目来自 `_probe_at_mouse()` 的射线结果。

代价是多了一层 `_owner_of()`（碰撞体 → 拥有者节点的向上查找）——
所有生成视图都把碰撞体放在自己名下，这是唯一需要知道这个形状的地方，已断言覆盖。

### 地形涂抹**不逐帧重建散布**
散布全量重建 138 ms（ART-11 实测），按住鼠标时每帧重建会卡死。
改为：**涂抹期间只重建地形网格（快），松开鼠标时才让散布追上**（一次）。

### 面板配色是**暖色调**，不是纯黑纯灰
纯黑在明亮田园场景旁像个洞，纯灰像电子表格。描边是**画出来的 1px**，
不用圆角/渐变/阴影——那是另一款游戏叠在上面。
