## 一句话
地形不平就自动适配地基，而不是直接拒绝建造。

## 要交付什么
- `FoundationState`：支撑点列表 + 地基类型 + 每点高度
- `FoundationSolver`：读高度场 → 算支撑点 → 输出 Level / Stepped / Column
- 第一版只需 Flat / Slight Slope（总纲 §13 明确允许）

## Definition of Done（总纲 §84 六问）
| # | 问题 | 答案 |
|---|---|---|
| 1 | 输入是什么 | 建筑 footprint + 地形高度场 |
| 2 | State 是什么 | `FoundationState`（支撑点、类型、每点高度） |
| 3 | Solver / Generator 是什么 | `FoundationSolver` |
| 4 | Runtime Node 是什么 | 地基 Mesh + Collider（新生成器） |
| 5 | 如何测试 | 平地 → Level；大坡度 → Stepped；断言地基顶面水平（各支撑点高度相同） |
| 6 | 如何证明没破坏旧系统 | **现有 headless 断言必须继续全绿** |

## 现有状态
`CozyFoundationValidator` 已能返回 `VALID_WITH_FOUNDATION` 并报出坡度差（`uneven by X m`），**但没有任何东西消费这个结果** —— 目前纯报告。`_ground_approves()` 只拒绝 INVALID，不处理 VALID_WITH_FOUNDATION。
