## 怎么用这套东西

**Willow 在新终端只需要说一句**：

```
继续做这个项目
```

或者直接点名：

```
做 ART-14
```

**然后 Claude 自己跑完整个循环，不需要再问**：

```
① 读本文件（站位 + 下一步）
        ↓
② 读当前板块笔记（交付内容 / DoD / 代码位置 / 现有状态 / 验收断言）
        ↓
③ 跑一次基线自检，确认是绿的 —— 不绿就先修基线，不叠新功能
        ↓
④ 按「当前站位」的下一步开工
        ↓
⑤ 做完按 03-流程/更新方案.md 更新五处：
   板块笔记 → 本目录 → 开发日志 → 仓库 ROADMAP → git 提交
        ↓
⑥ 报告：做了什么 / 关键决策 / 踩的坑 / 断言输出 / 下一步
```

**只有这几种情况才停下来问**：要拍板美术风格或素材、要改操作手感（相机等）、
总纲的硬规则跟代码冲突。其余一律自己判断并推进。

**要改架构时**才读 `../00-架构总纲/V2.2-技术架构总纲.md`。
