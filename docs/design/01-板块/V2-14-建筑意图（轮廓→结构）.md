## 要交付什么
- 玩家画建筑轮廓多边形 → 系统自动出墙 / 地板 / 门 / 窗 / 楼梯 / 屋顶

## Definition of Done（总纲 §84 六问）
| # | 问题 | 答案 |
|---|---|---|
| 1 | 输入是什么 | 建筑轮廓多边形 + 层数 + 材料 + 屋顶类型 |
| 2 | State 是什么 | BuildingState（已有）+ 轮廓记录 |
| 3 | Solver / Generator 是什么 | 轮廓 → 墙段列表生成器（含拐角闭合） |
| 4 | Runtime Node 是什么 | 复用 `CozyWall` 视图，由 Generator 批量 `submit_many` |
