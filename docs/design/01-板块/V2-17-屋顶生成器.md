## 一句话
屋顶按房间多边形推导，不是摆 Prefab。

## 交付了什么
- **`CozyRoofState`**（纯数据）：房号 / 多边形 / 檐口标高 / 脊高 / 风格 / 材料 / overhang
- **`CozyRoofGenerator`**：多边形 + 风格 → 屋脊 + 面片（**返回平面图，不返回 mesh**，
  所以布局可以直接断言，不用建任何东西）
- **支持 FLAT / GABLE / HIP** 三种风格（总纲 §31 要求的初期三种）
- **`CozyRoof`**（生成视图）：把平面图变成 mesh + 粗碰撞，**可淡出**
- 启动时按**顶层房间**自动生成屋顶

## 关键决策
- **生成器返回平面图，不返回 mesh**
  `plan()` 给的是面片顶点 + 屋脊线，视图才转成几何。这样"屋顶长什么样"可以**纯数据断言**，
  不必在测试里去翻 mesh。这一点直接决定了断言能写得多强。
- **屋脊沿长轴**：这样坡度永远是缓的那一侧。房子 8×6，屋脊沿 8m 方向。
- **非矩形房间降级为平顶，并如实上报**
  总纲 §31 的 HIP 是为矩形准备的；L 形房间做真双坡需要屋脊线分解，那是独立一块。
  **降级会体现在 `plan()["style"]` 里**，不是静默换掉。
- **碰撞体是覆盖整个 footprint 的粗盒子**
  玩家不会上屋顶，但遮挡射线必须能打到它。逐面碰撞是为无行为付代价。
- **必须可淡出**（§57）：平顶占位版已经把玩家盖住过；坡屋顶覆盖屏幕更多，只会更严重。
