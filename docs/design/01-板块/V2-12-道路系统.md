## 一句话
道路是连续 Path，不是 Tile 拼接。

## 要交付什么
- 玩家画路径 → 控制点 → 平滑样条 → 按宽度光栅化 → Terrain Mask → Grass/Soil 变 Road
- 道路本体草密度↓、路缘卵石/泥土密度↑（E.20.3）
- 材质 `road` 进材料表，默认不可建

## Definition of Done（总纲 §84 六问）
| # | 问题 | 答案 |
|---|---|---|
| 1 | 输入是什么 | 玩家画的 Path 控制点（世界 XZ） |
| 2 | State 是什么 | TerrainCell 的 material 变为 road；Path 数据本身也存（将来地形变宽要重算） |
| 3 | Solver / Generator 是什么 | 样条平滑 + 逐段宽度光栅化（复用 `CozyTerrainRaster`） |
| 4 | Runtime Node 是什么 | 无需新节点 —— 走地形贴图重绘（`CozyTerrainRenderer.rebuild_dirty()`） |
| 5 | 如何测试 | 画一条路，断言：沿线格 material=road、路外未变、脏区块数 ≈ 路径覆盖数 |
| 6 | 如何证明没破坏旧系统 | **现有 headless 断言必须继续全绿** |

## 现有状态
`CozyTerrainRaster.polygon_cells()` 与 `circle_cells()` 已可用且有 512 格精确断言。道路材质、Path 形状、样条均未做。`CozyTerrainIntent.Shape` 目前只有 POLYGON/CIRCLE/RECT。

## 验收断言（做完后应新增）
```
[cozyv2] road: %d cells along path, %d outside untouched, %d chunk(s) dirty  [OK]
```

## 下一步动作
1. `CozyTerrainMaterials` 加 `road`（`buildable_default: true`，`default_buildability: buildable`）
2. `CozyTerrainIntent` 加 `Shape.PATH` + `DRAW_ROAD`
3. 控制点 → 样条采样 → 相邻采样点间用矩形光栅化
4. 路缘规则（E.20.3）：路外一圈按概率撒卵石/泥土
